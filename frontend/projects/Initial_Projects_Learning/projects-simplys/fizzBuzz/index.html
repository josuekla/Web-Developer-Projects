Fizz Buzz Game

FizzBuzz é um desafio clássico de programação usado para treinar lógica e testar habilidades básicas em algoritmos. A ideia é simples: para uma sequência de números (geralmente de 1 a 100), o programa deve imprimir: "Fizz" se o número for múltiplo de 3, "Buzz" se for múltiplo de 5, "FizzBuzz" se for múltiplo de ambos (3 e 5), ou o próprio número, se não for múltiplo de nenhum deles.
