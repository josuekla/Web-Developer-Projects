# 🧠 FizzBuzz Game

Este é um projeto **simples** criado com o objetivo de:

- Treinar minha **lógica de programação**
- Praticar a **manipulação do DOM com JavaScript**
- Ver como é feita a **integração entre HTML, CSS e JS**

---

## 🚀 Como funciona?

O jogo FizzBuzz é um clássico da programação. Ele exibe os números de 1 a 100 com as seguintes regras:

- Se o número é múltiplo de 3 → mostra `Fizz`
- Se é múltiplo de 5 → mostra `Buzz`
- Se é múltiplo de **ambos** → mostra `FizzBuzz`
- Se não for múltiplo de nenhum → mostra o número

---

## 🛠️ Tecnologias usadas

- HTML5
- JavaScript (puro)
- Bootstrap 5 (para estilo básico)

---

## ▶️ Como executar

1. Abra o arquivo `index.html` no navegador.
2. Clique no botão **"Veja Agora"** para ver o resultado do FizzBuzz na tela.
