# 🚀 Minha Jornada de Desenvolvimento Web - 2024

Bem-vindo ao meu repositório de aprendizado! 🎯

Este repositório documenta minha jornada completa no desenvolvimento web, desde os primeiros passos em janeiro de 2024 até onde estou hoje. Cada pasta representa uma etapa do meu crescimento como desenvolvedor, mostrando a evolução gradual do conhecimento básico até conceitos mais avançados.

## 📖 Sobre Esta Jornada

Comecei do zero absoluto no início de 2024 e fui **aprendendo aos poucos,** **passo a passo,** construindo uma base sólida antes de avançar para tópicos mais complexos. Este repositório é um testemunho de dedicação, persistência e crescimento contínuo no mundo do desenvolvimento web.
